# 🍣 NiNi Sushi — сайт-меню с корзиной

Светлый сайт с лососёвым акцентом. Меню (30 блюд), фильтр по категориям,
4 языка (UA/RU/EN/VN), корзина, оформление заказа, регистрация через Supabase,
уведомление о заказе в Telegram/WhatsApp.

---

## 🚀 Как запустить

1. Открой папку `nini-sushi` в **VS Code**.
2. Самый простой способ посмотреть сайт — расширение **Live Server**
   (правый клик по `index.html` → *Open with Live Server*).
   Можно и просто открыть `index.html` в браузере двойным кликом.
3. Готово — сайт работает. Корзина и заказ через WhatsApp работают сразу,
   **без всякой настройки**.

## ⚙️ Настройка заказов и регистрации

Все настройки — в файле `js/supabase.js`, вверху в блоке `CONFIG`.

### Вариант A — без регистрации (работает сразу)
Ничего не настраивай. Заказ открывает **WhatsApp** с готовым текстом
(номер уже вписан: +84 367 021 338). Клиент жмёт «отправить» — заказ у тебя.

### Вариант B — авто-уведомление в Telegram
1. В Telegram найди **@BotFather**, создай бота → получишь **токен**.
2. Узнай свой **chat_id** (напиши боту **@userinfobot**).
3. Впиши в `CONFIG`:
   ```js
   TG_BOT_TOKEN: "сюда_токен",
   TG_CHAT_ID:   "сюда_chat_id",
   ```
Теперь заказы будут приходить тебе в Telegram автоматически.

### Вариант C — регистрация с паролями + база заказов (Supabase)
1. Зайди на **supabase.com**, создай бесплатный аккаунт и **New Project**.
2. В разделе **Project Settings → API** скопируй:
   - **Project URL** → в `SUPABASE_URL`
   - **anon public key** → в `SUPABASE_ANON_KEY`
3. В разделе **SQL Editor** вставь и запусти этот код, чтобы создать таблицу заказов:
   ```sql
   create table orders (
     id bigint generated always as identity primary key,
     created_at timestamptz default now(),
     customer_name text,
     phone text,
     address text,
     payment text,
     comment text,
     items jsonb,
     total bigint,
     user_id uuid
   );
   alter table orders enable row level security;
   create policy "anyone can insert" on orders for insert with check (true);
   ```
4. Регистрация/вход заработают сами. Заказы будут падать и в таблицу `orders`,
   и (если настроен) в Telegram.

> 💡 Лимиты бесплатного тарифа Supabase лучше глянуть на их сайте перед запуском —
> для старта их с запасом хватает.

## ✏️ Как добавить напитки

Открой `js/menu-data.js`, найди блок `НАПИТКИ` в самом низу массива `MENU`
и добавь позиции по образцу (он там закомментирован). Фото клади как
`img/menu/31.jpg` и т.д.

## ✏️ Как поменять цену
Там же, `js/menu-data.js` — поле `price` у нужного блюда (в донгах, без пробелов).
